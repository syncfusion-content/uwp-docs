# About Syncfusion UWP DatePicker Control

The SfDatePicker control allows the user to select date values in a touch-friendly manner.

## Normal view:

![UWP DatePickerDatePicker displaying the date in short format](Overview_images/Overview_img1.png)

## Expanded view:

![UWP DatePickerDatePicker displaying the selector to pick a date](Overview_images/Overview_img2.png)

## Key Features

- **Formatting** – The control displays the selected date value in various formats.

- **Date Selector** – The drop-down portion used for selecting the date can be customized.
