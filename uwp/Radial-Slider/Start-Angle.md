# Start Angle in UWP Radial Slider (SfRadialSlider)

The StartAngle property can be used to set the starting position for generating the ticks in the circular track.

{% tabs %}

{% highlight xaml %}

<syncfusion:SfRadialSlider x:Name="radialSlider" StartAngle="180" />

{% endhighlight %}

{% endtabs %}

{% tabs %}

{% highlight C# %}

radialSlider.StartAngle = 180;

{% endhighlight %}

{% highlight VB %}

radialSlider.StartAngle = 180

{% endhighlight %}

{% endtabs %}
